# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project is pinned to Expo SDK 54, not the latest SDK on npm. This was a deliberate downgrade from the default SDK 57 template because the Expo Go client used for on-device testing here only supports up to SDK 54. Do not run `npx expo upgrade` or bump the `expo` package without first confirming Expo Go client compatibility.
